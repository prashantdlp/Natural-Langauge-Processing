# NLP Project

This repository contains my implementations and experiments covering both classical and modern Natural Language Processing (NLP) techniques.

## Topics Covered

- Explored **text representation techniques**, including both classical and contextual **word embeddings**, and built complete **tokenization**, **lemmatization**, and **text filtering pipelines** using **NLTK** and **scikit-learn** to understand downstream NLP tasks.

- Developed an end-to-end **Spam Detection System** using **Logistic Regression**, and later implemented **TF–IDF feature extraction from scratch in C++**, gaining a deeper understanding of sparse text representations, term weighting, and vectorization.

- Fine-tuned pretrained Transformer-based language models for **sentiment analysis** on the **IMDB Movie Reviews** dataset, achieving **high classification accuracy**. Additionally, implemented a **Next-Token Prediction** task to study autoregressive language modeling.
